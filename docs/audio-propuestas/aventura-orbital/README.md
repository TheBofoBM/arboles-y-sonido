# Aventura orbital: banco integrado

Actualización del 23 de noviembre de 2026. Este banco está integrado en la
aplicación y se incluye en la compilación de GitHub Pages.

`biblioteca-postorden.wav` es una demo de ocho segundos: Libro → Autor → JOIN
→ Selección → Proyección, con la configuración predeterminada. Permite escuchar
la composición completa sin abrir la aplicación.

La música es original y usa grabaciones orquestales de VSCO 2 CE y campanas de
VCSL, con licencia CC0 1.0. Se adopta un carácter de aventura espacial con pulso
de 6/8; no se reutilizan las melodías de la propuesta de bloques musicales.

Los detalles de fuente, afinación y transformaciones están en
`src/assets/samples/aventura/ATRIBUCION.md` y `manifest.json` de ese directorio.
La calidad y el interés musical percibidos requieren la valoración del usuario;
las pruebas automáticas verifican el audio y su correspondencia estructural.
